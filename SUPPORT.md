# Support

## How to file issues and get help

Use [GitHub Issues](https://github.com/microsoft/FoundryLocalAndroid/issues) to
report SDK bugs or request features. Search existing issues before filing a new
one to avoid duplicates.

For setup and usage help, start with the [integration guide](docs/INTEGRATION_GUIDE.md)
and [troubleshooting guide](docs/TROUBLESHOOTING.md). If those resources do not
resolve the problem, open a GitHub issue with the SDK version, Android version,
deployment mode, and relevant logs.

## Microsoft Support Policy

Support for this project is limited to the resources listed above.
